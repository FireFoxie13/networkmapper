How to read this map
Line width = traffic volume · moving dots show direction, source → destination. A plain line is a configuration link with nothing flowing. Red = a rule denied the flow — hover the edge to see the layer and rule. Amber = impaired: nothing denied it, but the path can\'t complete (empty backend pool, failing health probe, SNAT exhaustion, an unconnected peering, a blackhole route, or an endpoint that never answered). Number in a circle = resources in that cluster · ×N = N links collapsed into one · ports (:443) and flow counts label traffic edges on hover.
